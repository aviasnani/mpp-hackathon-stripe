Repo health reports your agent can buy.

Send a GitHub repo, get a 0 to 100 health score, bus factor, activity and a missing-files checklist. Each report costs $0.02 and is paid inside the request over MPP. No API key, no account.

"Request a report" shows the raw 402 challenge. "Pay as demo agent" makes a real testnet payment from a server-side agent wallet and returns the report. The free sample always uses expressjs/express.
